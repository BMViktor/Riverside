Thin wrapper around the CDN Lucide set — the only icon source in this brand.

```jsx
<Icon name="waves" size={20} />
<Icon name="phone" size={16} label="Telefon" />
```

Requires `<script src="https://unpkg.com/lucide@latest/dist/umd/lucide.js"></script>` on the page. Always 1.5px stroke; never fill icons, never mix in emoji.
