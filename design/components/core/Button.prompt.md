The brand's action control: near-square (4px radius), medium weight Karla, no shadow.

```jsx
<Button variant="accent" size="lg" iconRight="arrow-right">Foglalás</Button>
<Button variant="secondary">Szobák megtekintése</Button>
<Button variant="ghost" iconLeft="phone">+36 30 123 4567</Button>
```

Variants: `primary` (pine, one per view), `accent` (clay, booking CTA only), `secondary` (hairline outline on white), `ghost` (inline/toolbar), `inverse` (over photography). Sizes 34/42/52px. Press state is a 1px downward nudge — never a scale or bounce.
